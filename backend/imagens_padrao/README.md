# Imagens padrão das ocorrências

Ilustrações SVG locais servidas pela API em `/imagens_padrao`.
O frontend exibe a imagem do setor responsável quando a ocorrência não tem fotos.
Sem setor definido, utiliza a categoria; sem correspondência, utiliza `servicos-publicos.svg`.

As ilustrações não são gravadas como anexos da denúncia. Fotos enviadas pelo usuário têm prioridade.
Para alterar a aparência, substitua o SVG correspondente mantendo seu nome.
