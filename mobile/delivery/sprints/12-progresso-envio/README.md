# 12 — Progresso do envio

Envie uma denúncia com fotos em uma conexão lenta. Confira as etapas de preservação, envio e espera pela confirmação do servidor. Quando o transporte informar o tamanho total, aparece percentual e barra acessível. Se não informar, o indicador permanece indeterminado. Upload de 100% ainda não significa denúncia aceita: o protocolo só aparece após a resposta válida da API.

Interrompa a rede durante o envio. O erro deve preservar o rascunho e a chave, permitindo Confirmar envio pendente. Faça o mesmo na correção de uma rejeitada. A medição real de bytes no Android físico permanece pendente; os testes exercitam os callbacks e os estados da interface.
